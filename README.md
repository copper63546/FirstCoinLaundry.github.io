# FirstCoinLaundry.github.io

Website for First Coin Laundry, 4877 Memorial Dr, Stone Mountain, GA 30083.

## Editing

- **Hours:** change the `HOURS` block near the bottom of `index.html`. Also update `openingHoursSpecification` near the top, which is what Google reads.
- **Photos:** add an `images/` folder with any of `storefront.jpg`, `washers.jpg`, `dryers.jpg`, `interior.jpg`. Each photo replaces its illustration automatically.
- **Phone / address:** search `index.html` for `404` or `4877` and update every match.
